# Patient Data Portal (mock-up)

A small front-end mock-up of a hospital patient portal that I made in early 2024 to practice HTML, CSS and vanilla JS.

There's a password screen (the demo password is `abc`), a searchable patient list and a details page for each patient. Every name and record is made up, and nothing talks to a server.

To try it, open `Index.html` in a browser.

It's an old project and isn't maintained.
